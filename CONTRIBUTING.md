# Contributing

Thanks for improving The Prompt Injectulator.

## Guidelines

- Keep pull requests small and focused.
- Preserve the repository's defensive security-testing intent.
- Do not include secrets, credentials, or private data in examples.
- Keep documentation and examples aligned with the MIT license.

## Local checks

Run the README structure smoke test before opening a PR:

```bash
bash tests/readme_sections_test.sh
```

## Pull request checklist

- [ ] Problem and change are clearly described.
- [ ] README/examples updated when behavior or usage guidance changes.
- [ ] Local checks pass.
