# Contributing

Thanks for contributing to The Prompt Injectulator.

## Ground Rules

- Keep changes focused and minimal.
- Preserve the repository's defensive LLM security testing intent.
- Do not include secrets, credentials, or sensitive internal data in prompts or examples.
- Keep contributions consistent with the MIT license in [`LICENSE`](LICENSE).

## Pull Request Checklist

- [ ] Clearly describe the problem and the proposed change.
- [ ] Update documentation when behavior or usage expectations change.
- [ ] Add or update tests/checks when practical.
- [ ] Confirm repository checks pass.

## Local Validation

Run the repository smoke test before opening a PR:

```bash
bash tests/readme_sections_test.sh
```

## Code of Conduct

Be respectful and constructive in all contributions.
